# Vendor Performance Data Analytics

## 📊 Project Overview

The **Vendor Performance Data Analytics** project analyzes vendor-related data to evaluate performance, identify trends, and generate insights that help businesses make data-driven decisions. The project covers data ingestion, preprocessing, analysis, and visualization using Python and Power BI.

---

## 🎯 Objectives

- Evaluate vendor performance using key metrics  
- Identify top-performing and underperforming vendors  
- Analyze trends to support procurement and business decisions  
- Present insights through an interactive Power BI dashboard  

---

## 🗂️ Repository Structure

```
Vendor-Performance-Data-Analytics/
├── ingestion_db.ipynb        # Data ingestion and preprocessing notebook
├── Vendor_Performance.pbix   # Power BI dashboard file
├── README.md                 # Project documentation
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/aryan-kaushal-12/Vendor-Performance-Data-Analytics.git
cd Vendor-Performance-Data-Analytics
```

---

### 2. Run the Data Ingestion Notebook

- Open `ingestion_db.ipynb` in Jupyter Notebook or Google Colab
- Run all cells to load, clean, and preprocess the data

---

### 3. Open the Power BI Dashboard

- Open `Vendor_Performance.pbix` in **Power BI Desktop**
- Explore the interactive dashboards and filters
